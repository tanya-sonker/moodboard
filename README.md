# Moodboard
A throwaway moodboard inspired by [Prada Vomit](https://x.com/maigosia/status/1640739482843615238?s=46&t=58ubjaq93M_ISiD785FUuw), the first prototype of Prada.com (2000).

## Inspiration
> "By the early 2000s, global brands such as Prada and Issey Miyake had established online presences. Aesthetic inspiration was drawn from Information Age optimism, using the novel affordances of browsers to employ music, layered overlay, and Flash-integrated video. An archetypal motif across early sites was the intentional use of pop-ups, repurposing them as a formal storytelling device. Designs like these celebrated the new medium of the internet as much as they attempted to communicate a message."
>
> — *The Early Websites of Fashion* by [Welcome Magazine](https://substack.com/home/post/p-196575751) (Substack)

## Features
- Allows text input and image uploads into tiny windows, reminiscient of the early 2000s pop-up format
- Text or image windows can be created from the toolbar
- Can either cascade or close all windows
- Windows can be dragged and resized to mimic a moodboard
